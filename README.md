# Tamakkun (تمكّن)

**Tamakkun** is a responsive Arabic (RTL) web platform for Grade 12 female students preparing for the **Qudurat** (General Aptitude Test) and **Tahsili** (Achievement Test) exams.

It brings learning resources and progress tracking together in one place for students. School counselors use it to follow student progress and step in when a student needs support.

---

## Features

### For students
- **Learning resources**: structured content for Qudurat (quantitative and verbal sections) and Tahsili.
- **Educational videos**, organized by subject and topic.
- **Official exam links**: direct access to official registration and information portals.
- **Daily challenges** to keep up regular practice.
- **Motivational content** for encouragement during preparation.
- **Exam date and score tracking**: record upcoming exam dates and the scores received.
- **Personal progress monitoring**: track activity, performance and growth over time.

### For school counselors
- **Student monitoring**: view each student's activity and progress.
- **Follow-up identification**: find students who need extra attention or support.
- **Score and activity review**: review exam scores and platform engagement.
- **Content management**: add, edit and organize learning resources, videos and challenges.
- **Announcements**: send announcements to students.
- **Reports**: generate reports on student performance and activity.

## Tech Stack

| Layer      | Technology                    |
|------------|-------------------------------|
| Backend    | Laravel 13 (PHP 8.3)          |
| Database   | MariaDB / MySQL               |
| Templating | Blade                         |
| Frontend   | Alpine.js, Tailwind CSS       |
| UI         | Mobile-friendly, Arabic RTL   |

The architecture is designed to **support a future mobile application** (for example, through an API layer that can be shared with mobile clients).
